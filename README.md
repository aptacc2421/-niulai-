# 直立牛平原（《牛来》粉丝二创 3D 游戏）

> 策划阶段 · 粉丝二创 · 非官方 · 不商用

## 项目简介

一款 3D 低模步行冒险游戏：主角牛来是一头"生下来就站不起来的牛"，在直立牛与奇奇怪怪梗生物共存的大平原上收集"地摊鸡汤"语录卡——**镜头高度 = 站立值**，听完 36 句、集齐怪团，你就站起来了。

## 目录结构

- `直立牛平原_策划文档.md` — 完整策划文档（v0.3.x，含梗清单、选座购票、蛇追戏、还原清单）
- `photo/` — 角色参考图（牛来、牛妈妈、路人牛、耄耋×2、奶娃×2、蛇）；仅开发对照用，不进入游戏素材
- `src/`（规划中）— M1 起的三维原型代码（Three.js）
