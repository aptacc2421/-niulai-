## 怎么玩（M1 原型）

任选其一：
- 直接双击 `index.html`（浏览器打开即可，无需安装任何东西）
- 或本地起个静态服务：`python3 -m http.server 8080` 后访问 `http://127.0.0.1:8080/`

操作：WASD/方向键移动（爬）· 鼠标右键转视角 · E 对话 · Tab 图鉴 · M 导演模式（线稿）· F 哞 · K 静音

M1 内容：牛棚镇 + 导演牛/妈妈牛/爬行老牛/路人牛 + 耄耋哈气对话 + 3 张语录卡 + 草票拾取。
M2a 内容：K 线交易场（东门走出去）——红涨绿跌柱地形 + 股民牛/韭菜牛 + 奶龙休假告示 + 2 张新语录卡。
M2b 内容：草浪区蛇追戏——被蛇咬会叫妈妈（妈妈牛狂奔救场）+ 逃出得卡 + 蛇蜕皮换卡 + 玄学牛。
M2c 内容：电影院废墟选座购票——满场座位拼"牛→来→牛来→发"字 + 票根收藏 + 影院经理牛。
M2d 内容：奇奇怪怪生物团——奶娃跟班/卡皮巴拉/菜狗/尖叫鸡/吗喽/绿头鱼/修勾/猪猪侠/花花 + 隐藏怪 + 17 张语录卡。
镜头高度 = 站立值：听鸡汤越多，镜头越高，直到你站起来。
