# 直立牛平原（《牛来》粉丝二创 3D 游戏）

> 策划阶段 · 粉丝二创 · 非官方 · 不商用

## 项目简介

一款 3D 低模步行冒险游戏：主角牛来是一头"生下来就站不起来的牛"，在直立牛与奇奇怪怪梗生物共存的大平原上收集"地摊鸡汤"语录卡——**镜头高度 = 站立值**，听完 36 句、集齐怪团，你就站起来了。

## 目录结构

- `直立牛平原_策划文档.md` — 完整策划文档（v0.3.x，含梗清单、选座购票、蛇追戏、还原清单）
- `photo/` — 角色参考图（牛来、牛妈妈、路人牛、耄耋×2、奶娃×2、蛇）；仅开发对照用，不进入游戏素材
- `index.html` + `src/` + `lib/` — **M1 可玩原型**（Three.js，无构建、无依赖安装）

## 怎么玩（M1 原型）

任选其一：
- 直接双击 `index.html`（浏览器打开即可，无需安装任何东西）
- 或本地起个静态服务：`python3 -m http.server 8080` 后访问 `http://127.0.0.1:8080/`

操作：WASD/方向键移动（爬）· E 对话 · Tab 图鉴 · M 导演模式（线稿）· F 哞 · K 静音

M1 内容：牛棚镇 + 导演牛/妈妈牛/爬行老牛/路人牛 + 耄耋哈气对话 + 3 张语录卡 + 草票拾取。
镜头高度 = 站立值：听鸡汤越多，镜头越高，直到你站起来。
