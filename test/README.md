# 冒烟测试（可选，但做了更好）

用无头浏览器自动验证游戏能跑：加载 → 开始 → 移动 → 导演牛对话得卡 → 耄耋哈气对话得卡 → 无 JS 报错。

## 跑法

```bash
cd test
npm install    # 首次需要（会装 puppeteer，需 Node.js 环境）
npm run smoke
```

看到 `=== 冒烟测试 PASS ===` 就是全绿。截图输出到 `/tmp/zhili_niu_smoke.png`。

## 说明

- 测试内置一个静态服务器，不需要手动起服务
- 跑不动没关系：手动双击 `index.html` 玩一遍、PR 里说一声"我玩过了，正常"也可以
- 完整测试套件目前不必要（粉丝项目、快速迭代），但**别把冒烟测试跑挂了**
